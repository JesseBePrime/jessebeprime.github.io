Mechanical redesign

Ankle exoskeleton drivetrain redesign

A targeted redesign of the transmission and wearable interface for an existing powered ankle exoskeleton prototype.

Role
Mechanical redesign and implementation
Focus
Drivetrain retention, tolerances, and user interface
Tools
SolidWorks, engineering drawings, 3D printing
Context

Improving an existing integrated exoskeleton

A previous graduate student created the first iteration of the device, including enclosed actuation, electronics, and power. Testing exposed two practical issues: gear slip could interrupt the drivetrain, and the wearable interfaces did not provide the intended assistance consistently.

My work concentrated on the mechanical paths most directly connected to those failures while preserving the compact integrated architecture of the original system.

Design response

The redesign strengthens torque transfer and makes the interface easier to adapt

I redesigned the drivetrain around positive gear retention and tighter component control. Locking pins resist gear slip, higher-tolerance shafts improve alignment, and gear couplers support dependable torque transmission through the assembly.

I also developed a universal shank interface so the exoskeleton could be configured more consistently for the user. The work included CAD, detailed drawings, and implementation of the redesigned and 3D-printed components.

  • Locking pins added to prevent gears from slipping on their shafts
  • Higher-tolerance shafts and couplers used to improve alignment
  • Universal shank interface developed for the wearable connection
Contribution

A focused mechanical update within a larger collaborative system

This project required working within an established architecture and distinguishing the previous designer's system-level contribution from my own. My responsibility covered the drivetrain changes, the updated user interface, the associated CAD, and the hardware implementation needed to integrate those revisions into the existing device.
